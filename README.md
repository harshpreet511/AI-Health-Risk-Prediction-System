# AI Health Risk Prediction System

An educational machine learning project developed using Python to predict health risk levels based on selected health-related inputs.

## Project Overview

The AI Health Risk Prediction System is a Python-based desktop application that uses a trained machine learning model to classify health risk into three categories:

* Low Risk
* Medium Risk
* High Risk

## Technologies Used

* Python
* Machine Learning
* NumPy
* Pandas
* Matplotlib
* Tkinter
* Joblib

## Project Features

* User-friendly graphical interface.
* Accepts health-related inputs such as age, weight, waist size, pulse rate, blood pressure, and cholesterol.
* Uses a trained machine learning model.
* Displays a predicted health risk category.

## How to Run the Project

1. Install Python on your computer.
2. Install the required libraries:

```bash
pip install numpy pandas matplotlib scikit-learn joblib
```

3. Open the project folder.
4. Run the application:

```bash
python health_app.py
```
